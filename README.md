# PDF Context Menu Merger

A small Windows utility for merging selected PDF files from File Explorer.

## Features

- Merge multiple PDF files from the Windows `Send to` menu.
- Save the output next to the first selected PDF.
- Use `merged.pdf` by default, then `merged_001.pdf`, `merged_002.pdf`, and so on when needed.
- Run silently in the background on success.
- Show a message box only when an error occurs.
- Optional Total Commander configuration hint is generated during installation.

## Requirements

- Windows
- Python 3.8 or later
- `pypdf`

The installer installs `pypdf` automatically. You can also install it manually:

```powershell
python -m pip install -r requirements.txt
```

## Install

Run from PowerShell:

```powershell
Set-Location 'C:\path\to\PDF Context Menu Merger'
& '.\setup_context_menu.bat'
```

The installer registers:

- PDF right-click menu item: Chinese label meaning `Merge PDF`
- File Explorer `Send to` shortcut: Chinese label meaning `Merge PDF`

For merging multiple PDFs, use:

```text
Select multiple PDF files -> Right click -> Send to -> Merge PDF menu item
```

## Uninstall

Run:

```powershell
& '.\setup_context_menu.bat' uninstall
```

## Notes

`merge_pdf_sendto.vbs` is generated by the installer and contains local absolute paths. It is intentionally ignored by Git.
